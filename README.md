# Geomate — well log correlation

Веб-инструмент для геологов: загрузка каротажа (LAS), корреляция скважин со
стратиграфическими разбивками и литологией, импорт/экспорт данных. Первый
вертикальный срез на пути к веб-аналогу Petrel.

Работает целиком в браузере — данные хранятся локально (IndexedDB), бэкенд не нужен.

## Возможности

**Данные**
- **Импорт LAS 2.0** — собственный парсер, устойчивый к `WRAP=YES`, разным `NULL`,
  лишним пробелам и отсутствующим единицам. Drag-and-drop нескольких файлов + демо.
- **Импорт разбивок (tops) из CSV/TSV** — колонки `well / surface / depth`
  (RU/EN, разделитель `, ; таб`), матчинг скважин по имени, слияние одноимённых пластов.
- **Импорт литологии из CSV/TSV** — `well / top / base / lithology / saturation`;
  литотипы и насыщение (RU/EN) маппятся в доменные цвета и паттерны.

**Корреляция**
- **Планшет на canvas** — авто-раскладка треков по мнемоникам (GR/SP/Caliper,
  Resistivity на лог-шкале, Porosity/Density), литологическая колонка + лента насыщения.
- **Интерактивные tops** — инструмент «Маркер» ставит разбивку на всех скважинах;
  перетаскивание ручки меняет глубину по скважине (снап к границам пластов),
  линии идут «ступенькой» между скважинами.
- **Инспектор невязок** — глубины по скважинам, Δ между соседними, редактирование.
- **Клавиатура** для выбранного маркера: `Del` — удалить, `↑/↓` — глубина
  (`Shift` ×10), `Esc` — снять выделение.
- **Хедер скважины** — развернуть на весь экран, показать/скрыть треки и литологию.
- Зум по глубине колесом, панорама перетаскиванием, синхронный курсор.

**Экспорт**
- **Разбивки (CSV)** и **Литология (CSV)** — round-trip с импортом.
- **Планшет (PNG)** — весь экран корреляции (2×, с рейкой и маркерами).

**Проекты**
- Мультипроектность в IndexedDB: создать / переключить / переименовать / удалить.
- Автосохранение изменений, восстановление при перезагрузке.

## Стек

React 18 + TypeScript · Vite 8 · Zustand · Canvas 2D · Lucide (иконки) · Vitest.

## Быстрый старт

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. Нажмите **«Демо»** (можно дважды) — увидите
корреляционную схему с литологией и маркерами.

## Команды

```bash
npm run dev        # дев-сервер (HMR)
npm test           # юнит-тесты (парсеры, экспорт)
npm run typecheck  # проверка типов
npm run build      # прод-сборка в dist/
npm run preview    # локальный предпросмотр прод-сборки
```

## Форматы CSV

**Разбивки (tops):**

```csv
Well,Surface,MD
UT-1058,Top A,2048
UT-1058,KP S8,2096
UT-1059,Top A,2055
```

**Литология:**

```csv
Well,Top,Base,Lithology,Saturation
UT-1058,2000,2030,Sandstone,Oil
UT-1058,2030,2060,Shale,
UT-1058,2060,2095,Limestone,Water
```

Имена колонок распознаются гибко (RU/EN), разделитель — запятая, точка с запятой
или таб; десятичная запятая поддерживается.

## Деплой

Приложение статическое (client-side SPA без роутинга) — деплоится на любой
static-хостинг. Сборка кладётся в `dist/`.

**Vercel** — zero-config: подключите репозиторий, framework preset «Vite»
(build `npm run build`, output `dist`).

**Netlify** — конфиг уже есть в [`netlify.toml`](netlify.toml). Подключите репозиторий,
остальное подхватится.

**Любой static-хостинг** (GitHub Pages, S3, nginx):

```bash
npm run build
# раздать содержимое dist/
```

## Структура

```
src/
  types.ts                 модель данных (Well/Curve/LithoInterval/Marker/…)
  store.ts                 стор приложения (Zustand) + импорт tops/литологии
  persistence.ts           мультипроектная персистентность (IndexedDB)
  App.tsx                  каркас UI, корреляция, горячие клавиши
  las/parser.ts            парсер LAS 2.0 → Well
  tops/csv.ts              парсер CSV разбивок
  lithology/csv.ts, map.ts парсер + маппинг литологии/насыщения
  plate/                   шаблон планшета, шкалы, демо-литология
  components/
    WellLogPlate.tsx       canvas-планшет (треки, литология, зум/панорама)
    CorrelationMarkers.tsx оверлей маркеров (ступеньки, ручки, снап)
    MarkerInspector.tsx    инспектор невязок
    ImportModal.tsx        импорт tops/литологии
    ExportMenu.tsx         экспорт CSV/PNG
    ProjectMenu.tsx        переключатель проектов
  export/                  сборка CSV (tops, литология) и PNG-планшета
```
