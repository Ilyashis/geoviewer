# GeoViewer — веб-аналог Petrel

Веб-инструмент для геологов: от загрузки каротажа (LAS) и корреляции скважин до
структурных карт, подсчёта запасов и первого сейсмического модуля. Целиком в браузере —
данные хранятся локально (IndexedDB), бэкенд не нужен.

Полная карта того, что построено и почему — [docs/product/overview.md](docs/product/overview.md).
Архитектурные решения — [docs/architecture/](docs/architecture/).

## Возможности

**Данные**
- **Импорт LAS 2.0** — собственный парсер, устойчивый к `WRAP=YES/NO`, разным `NULL`,
  футам→метрам, лишним пробелам и «грязным» реальным файлам. Drag-and-drop нескольких
  файлов + демо.
- **Импорт разбивок (tops) из CSV/TSV** — колонки `well / surface / depth`
  (RU/EN, разделитель `, ; таб`), матчинг скважин по имени, слияние одноимённых пластов.
- **Импорт литологии из CSV/TSV** — `well / top / base / lithology / saturation`;
  литотипы и насыщение (RU/EN) маппятся в доменные цвета и паттерны.
- **Импорт инклинометрии (survey CSV)** — MD/Inc/Azi → траектория (метод минимальной
  кривизны), TVD/снос по стволу.
- **Импорт устьев** — таблица `скважина, X, Y, KB`. Нужен для карт: реальные выгрузки
  (Petrel) координат и альтитуд в LAS не пишут.
- **Импорт `.dev` (Petrel well trace)** — кидается вместе с LAS одной пачкой: X/Y/KB из
  шапки (тогда таблица устьев не нужна) + траектория из MD/X/Y/Z.
- **Онбординг** — приветственный экран, один клик — богатое демо-месторождение
  (6 скважин, зоны, литология, часть стволов наклонная).

**Корреляция**
- **Планшет на canvas** — авто-раскладка треков по мнемоникам (GR/SP/Caliper,
  Resistivity на лог-шкале, Porosity/Density), литологическая колонка + лента насыщения.
- **Интерактивные tops** — инструмент «Маркер» ставит разбивку на всех скважинах;
  перетаскивание ручки меняет глубину по скважине (снап к границам пластов),
  линии идут «ступенькой» между скважинами.
- **Инспектор невязок** — глубины по скважинам, Δ между соседними, редактирование.
- **«Привязка»** — редактируемая матрица пластов × скважин (полнота, невязки построчно).
- **«Дашборд»** — сводка проекта: статистика по кривым, состав литологии, разброс невязок.
- Клавиатура для выбранного маркера, полноэкранный хедер скважины, зум/панорама,
  синхронный курсор.

**Карта — структура, изохоры, запасы**
- **Структурные карты** по кровлям (IDW-грид + изолинии), TVDSS с учётом наклона ствола.
- **Изохоры** (толщина между двумя кровлями) → подсчёт запасов.
- **Net pay из логов** — N/G·φ·Sw с настраиваемыми отсечками, вместо ручных чисел
  (ручной ввод остаётся запасным путём). Мнемоники RU+EN (ГК/БК/ГГКП и GR/RESD/RHOB),
  φ — по готовой кривой, плотности или акустике; метод и кривые видны в панели.
- **Контакт ВНК** — клип объёма по флюидному контуру.
- **Полигон выклинивания** — рисуется на карте кликами, клипует объём по реальной
  границе резервуара.
- **Разломы** — трасса на карте рвёт интерполяцию грида; сброс **вычисляется** из
  гриддинга по обе стороны, а не вводится вручную. Разлом — плоскость, секущая разрез:
  по умолчанию все пласты (лишние снимаются), со **своим сбросом на каждом пласте**.
- **P90/P50/P10** — Монте-Карло по треугольным распределениям параметров.
- **Сводка запасов** по всем пластам сразу, экспорт отчёта (CSV/PDF).

**Сейсмика**
- Синтетический 2D-разрез вдоль линии скважин — демо-мост к реальному сейсмо-импорту,
  та же методика перенесётся на SEG-Y.
- **Автотрекинг горизонта** по амплитуде + **ручная правка** узлов перетаскиванием.
- **Модель скорости** time↔depth в общем ядре (постоянная и V₀+k·z).
- **Калибровка V₀/k по скважинам** — подбирается МНК по привязкам, не вводится руками;
  тем же действием горизонт прижимается точно на скважины.
- **Две пересекающиеся линии** (W→E, S→N) с loop-tie QC на пересечении.
- Снятый горизонт → те же контрольные точки → тот же движок гриддинга, что и для
  скважин — сейсмика интегрирована в общий структурный каркас, а не отдельная песочница.

**Кроссплоты**
- NPHI-RHOB и другие пары кривых, цвет по третьей переменной, гистограммы,
  фильтр по зоне/активной скважине, лог-шкалы.

**Экспорт**
- **Разбивки (CSV)** и **Литология (CSV)** — round-trip с импортом.
- **Планшет (PNG)** — весь экран корреляции (2×, с рейкой и маркерами).
- **Отчёт о запасах (CSV/PDF)** — параметры, объёмы, P90/P50/P10.

**Проекты**
- Мультипроектность в IndexedDB: создать / переключить / переименовать / удалить.
- Автосохранение изменений, восстановление при перезагрузке.

## Стек

React 18 + TypeScript · Vite 8 · Zustand · Canvas 2D · Lucide (иконки) · Vitest.

## Быстрый старт

```bash
npm install
npm run dev
```

Откроется на `http://localhost:5173`. Нажмите **«Демо»** (можно дважды) — увидите
корреляционную схему с литологией и маркерами.

## Команды

```bash
npm run dev        # дев-сервер (HMR)
npm test           # юнит-тесты
npm run test:watch # тесты в watch-режиме
npm run typecheck  # проверка типов
npm run build      # прод-сборка в dist/
npm run preview    # локальный предпросмотр прод-сборки
```

## Форматы CSV

**Разбивки (tops):**

```csv
Well,Surface,MD
UT-1058,Top A,2048
UT-1058,KP S8,2096
UT-1059,Top A,2055
```

**Литология:**

```csv
Well,Top,Base,Lithology,Saturation
UT-1058,2000,2030,Sandstone,Oil
UT-1058,2030,2060,Shale,
UT-1058,2060,2095,Limestone,Water
```

**Инклинометрия (survey):**

```csv
Well,MD,Inc,Azi
UT-1059,0,0,97
UT-1059,1600,0,97
UT-1059,2200,34,97
```

Имена колонок распознаются гибко (RU/EN), разделитель — запятая, точка с запятой
или таб; десятичная запятая поддерживается.

## Деплой

Приложение статическое (client-side SPA без роутинга) — деплоится на любой
static-хостинг. Сборка кладётся в `dist/`.

**Vercel** — zero-config: подключите репозиторий, framework preset «Vite»
(build `npm run build`, output `dist`).

**Netlify** — конфиг уже есть в [`netlify.toml`](netlify.toml). Подключите репозиторий,
остальное подхватится.

**Любой static-хостинг** (GitHub Pages, S3, nginx):

```bash
npm run build
# раздать содержимое dist/
```

## Структура

```
src/
  types.ts                  модель данных (Well/Curve/LithoInterval/Marker/…)
  App.tsx                   каркас UI, табы, горячие клавиши
  persistence.ts            мультипроектная персистентность (IndexedDB)
  sampleData.ts             генератор демо-LAS

  core/                     общее ядро — используется И скважинами, И сейсмикой
    crs/                    единицы, система координат, TVDSS-датум
    velocity/               модель time↔depth (const, V₀+k·z) + калибровка по скважинам
    geom/                   IDW-грид, изолинии, точка-в-полигоне, пересечения, разломы
    framework/              buildSurface — единая точка сборки поверхности из точек любого источника

  store/                    Zustand, слайсы (wells / markers / project / framework)

  las/parser.ts             парсер LAS 2.0 → Well
  tops/csv.ts               парсер CSV разбивок
  lithology/                парсер + маппинг литологии/насыщения
  survey/csv.ts             парсер CSV инклинометрии

  wells/                    петрофизика (net pay), TVD-траектория, агрегация кроссплотов
  reserves/                 объёмный расчёт, Монте-Карло, сводка запасов по пластам
  seismic/                  синтетический разрез, автотрекинг, горизонт → каркас

  plate/                    шаблон планшета, шкалы, демо-литология

  components/
    WellLogPlate.tsx        canvas-планшет (треки, литология, зум/панорама)
    CorrelationMarkers.tsx  оверлей маркеров (ступеньки, ручки, снап)
    MarkerInspector.tsx     инспектор невязок
    WellTie.tsx             матрица пластов × скважин («Привязка»)
    Dashboard.tsx           сводка проекта
    WellMap.tsx             карта: структура/изохоры/запасы/полигоны/разломы
    SeismicView.tsx         сейсмо-разрез: пикинг, ручная правка, калибровка, линии
    CrossplotView.tsx       кроссплоты и гистограммы
    ReservesSummary.tsx     сводка запасов по всем пластам
    ImportModal.tsx, ExportMenu.tsx, ProjectMenu.tsx

  export/                   сборка CSV/PNG/PDF (tops, литология, запасы, планшет)

  architecture.test.ts      граница модулей: core ← wells ∥ seismic ← reserves
```
